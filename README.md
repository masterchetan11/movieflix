🍿 MoveFlix: Simple Movie Search & Recommendations
A straightforward, client-side web application designed to help you quickly search for movies and get instant, basic suggestions.

✨ Key Features
Quick Search: Find any film instantly using its title.

Instant Details: View essential movie metadata: synopsis, release year, rating, and poster image.

"Similar To" Suggestions: Get simple, non-personalized recommendations based on the currently viewed film (e.g., matching genres).

🛠️ Technology Used
This project is built to be lightweight and fast:

Frontend: [HTML, CSS, Vanilla JavaScript]

Data Source: [TMDB API / OMDb API] (The Movie Database or Open Movie Database)

🚀 Getting Started
Getting MoveFlix up and running is simple and requires only a few steps.

Prerequisites
You only need a modern web browser.

Installation & Run
Clone the repository:

Bash

git clone [https://github.com/masterchetan11/movieflix]
cd MoveFlix
Open the main JavaScript file (js/script.js or wherever your key is used) and insert your key where prompted in the code.

Launch the App:

Simply double-click the index.html file in your file explorer. It will open in your default browser and is ready to use!
